# Contributing to VisionSpeak

Thank you for your interest in contributing to VisionSpeak! This project provides offline, local AI image captioning with zero API keys.

## Development Workflow
1. Create a feature branch off \main\ (\eat/your-feature-name\).
2. Make modular, focused changes.
3. Run local unit tests: \pytest tests/unit\.
4. Submit a Pull Request targeting \main\ with clear testing steps and acceptance criteria.

## Code Standards
- Python: PEP 8 guidelines, type hints where applicable.
- JavaScript/React: ES6+ modules, functional components, hooks.
- Commit messages: Follow conventional commits format (\eat:\, \ix:\, \docs:\, \	est:\, \chore:\).
