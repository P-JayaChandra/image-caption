# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
VisionSpeak is strictly an offline, local application. It does not transmit telemetry, images, or captions over external networks.

If you discover a security vulnerability (such as malicious image payload processing, arbitrary code execution, or path traversal), please email:
**jayachandrapilla1434@gmail.com**

Please do not open public issues for sensitive vulnerabilities.
